# getlight.sherhn.space — GitHub Pages

Домен и контакты уже прописаны в HTML, sitemap и OG. В dist/CNAME указан getlight.sherhn.space.

После самостоятельной загрузки сайта:

1. В репозитории откройте Settings > Pages.
2. Выберите источник Deploy from a branch и папку /(root), если загрузили содержимое dist в корень ветки публикации.
3. В Custom domain укажите getlight.sherhn.space.
4. У DNS-провайдера создайте CNAME getlight → <владелец-репозитория>.github.io (без имени репозитория).
5. После подтверждения домена включите Enforce HTTPS.

DNS настраивает владелец самостоятельно. При подготовке проекта DNS не изменялся.

Документация: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site
